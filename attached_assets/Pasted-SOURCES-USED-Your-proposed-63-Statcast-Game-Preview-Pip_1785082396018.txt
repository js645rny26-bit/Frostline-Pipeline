Three corrections before starting

1. Resolve the raw-payload path contradiction

The current path:

artifacts/statcast-preview/YYYY-MM-DD/<gamePk>.json

cannot preserve multiple fetches without overwriting earlier payloads.

Use:

artifacts/statcast-preview/YYYY-MM-DD/<gamePk>/<fetchTimestamp>.json

Optionally maintain a separate latest.json pointer or manifest. The immutable timestamped payload is the audit record.

2. Clarify failure semantics

The specification uses “fail-closed,” but also correctly says the wider pipeline continues when Statcast is missing.

Use this explicit distinction:

Overall Frostline pipeline: fail-open when Statcast preview is unavailable
Statcast-derived influence: fail-closed to zero
Authorization: unchanged

That prevents Replit from freezing an entire slate because one optional preview source failed.

3. Expand the relevant-file instruction

The listed files are not enough to investigate the misleading timestamp behavior. Add:

Locate and inspect the module or source adapter that currently populates DAILY_MATCHUPS.Statcast_Last_Updated, including any shared refresh-timestamp helper. Do not assume module09 owns this field.

This is important because the identical FanGraphs and Statcast timestamps likely originate upstream of module09.
